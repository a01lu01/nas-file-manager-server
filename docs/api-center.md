# API 中心与 OA 系统集成计划

记录日期 2026-11-12。API 中心纳入 NFM Server 功能计划，为自研 OA 提供文件列表、详情、上传、下载和删除入口，并配套应用授权、开发文档与调用记录。根据同日用户补充，增加 NAS 账号创建及相关管理、权限查询与修改接口。当前处于设计阶段，实现与验收按路线图推进。

文件接口先按 OA 后端持有独立应用凭据、绑定专用 NAS 执行身份来起草。账号及权限管理另行登记管理后端、应用管理能力和可管理范围。员工级 NAS 权限映射、管理后端、具体认证协议、路径和字段在实施前确定。API 实现将复用套件统一的根映射、权限、上传收尾和作业能力，整体边界参见服务设计。[服务设计](design.md)

## 1. 管理入口

NAS 管理员在 API 中心登记 OA 应用，配置可用目录、操作权限和资源预算。API 中心包含以下功能。

| 管理项 | 计划内容 |
| --- | --- |
| 应用登记 | 创建应用标识、记录用途与负责人，启用、暂停及撤销应用 |
| 凭据管理 | 签发、轮换与撤销应用凭据，查看有效期和最近使用状态 |
| 目录与能力 | 配置授权根、相对路径范围和列表／详情／上传／下载／删除权限，展示实际可用能力 |
| 账号与权限管理 | 登记 NAS 管理后端、可管理账号／组、目录和可授予权限上限，分别授予查询、创建、资料／状态修改、密码重置、分组和权限调整能力 |
| 开发文档 | 查看版本化 OpenAPI 文档、请求与响应示例、错误说明以及服务地址 |
| 在线调试 | 以已授权身份查看接口结果，展示上传／删除、账号变更和权限调整的目标与非敏感参数，由使用者主动提交 |
| 调用记录 | 按应用、请求 ID、操作、状态和时间查询调用情况，汇总流量与限流情况，关联账号／权限变更的受限审计记录 |
| 任务管理 | 查看本人应用的上传／删除、账号开通和批量权限任务、进度、确认结果及停止状态 |

服务对 OA 公布经管理员配置的 HTTPS API 基址、接口版本和能力。应用管理权限与业务调用权限分别授予对应角色，中文、香港繁体中文和英文覆盖管理界面、说明与辅助功能名称。

## 2. 应用身份与文件授权

- 推荐 OA 后端保管应用凭据，通过认证取得有期限的受限访问令牌。浏览器端的文件页面由 OA 后端代理业务调用，文件内容使用流式转发。面向浏览器直传／下载的授权形式可在 OA 接入时进一步确定。
- 管理员为应用绑定专用 NAS 执行身份及授权根。有效权限取应用授权与真实 NAS 权限的交集，查询、上传、下载和删除分别检查。受限上传收尾沿用管理员明确登记的代理授权。
- OA 传入的业务用户 ID 可作为审计上下文，具体文件授权使用已核验的执行身份。若需要逐员工继承 NAS 权限，先建立可验证的员工与 NAS 身份映射及委托，再授予相应能力。
- 凭据签发后由 OA 后端保管，服务安全保存必要校验信息和执行身份配置。访问令牌绑定应用、服务实例、授权范围与有效期，支持轮换和撤销，凭据通过受控方式交付。
- 每次请求校验令牌、应用状态、操作能力和目录范围。撤销后的新请求返回明确错误，进行中任务按实际停止与结果核对流程收尾。

## 3. 文件定位与查询

文件定位沿用授权根 ID 和相对路径，NAS 服务端将其解析为已核验的实际目录。文件详情可返回后端提供的对象或版本标识，用于后续下载与修改的条件校验。

| 接口能力 | 请求与响应内容 |
| --- | --- |
| 文件列表 | 当前目录、分页游标、每页上限、名称／日期排序和类型筛选，返回条目与下一页标识 |
| 文件详情 | 名称、文件／目录类型、相对路径、文件大小、修改时间、可用媒体类型及对象／版本信息 |
| 授权目录 | 返回当前应用可访问的根 ID、展示名称及对应操作能力 |
| 服务能力 | 返回 API 版本、服务实例及该应用当前可用能力 |

列表默认查询当前层级，目录统计按明确请求和资源预算执行。目录变化时定义分页刷新与失效处理，稳定性以实际后端能力为依据。大小、时间和版本字段声明可空规则、时间单位与精度，方便 OA 可靠处理不同 NAS 的返回值。

相对路径支持中文、空格与特殊字符，约定统一编码和规范化规则。路径解析与符号链接访问经过根边界核验，修改时再次核对目标身份和版本。

## 4. HTTP 上传与正式提交

OA 通过 HTTP 上传文件内容，服务负责有界流式接收。上传数据通道接入统一任务登记、对象归属、完整性核验和正式提交能力，与 App 上传共用结果语义。

1. OA 创建上传任务，提供授权根、目标相对路径、名称、预期大小与约定的校验信息。服务登记应用和执行身份，排他创建或可信认领本任务临时对象。
2. OA 发送文件内容，服务记录已确认写入位置。分块／续传形式在接口契约中确定，明确偏移、重复数据、完整性和并发写入的处理。
3. 发送中断后查询原任务与确认位置，核对临时对象身份后继续。重试使用原任务及幂等标识，应用和任务归属持续校验。
4. 数据发送完成后调用完成接口，服务核验大小、版本与约定的完整性要求，再提交正式文件。响应记录实际最终名称、文件定位信息及核验结果。
5. 同名文件沿用编号与排他认领策略，正式提交成功后返回最终结果。提交结果待确认时通过原任务查询和只读核对收尾。
6. 取消时停止后续写入，清理已确认属于本任务的临时对象，并分别记录停止与清理结果。

OA HTTP 上传使用统一受限收尾能力时，也须满足管理员的代理授权和文件归属要求。临时区、目标文件系统、属主与 ACL 的验证沿用服务设计第 5 节。

## 5. 下载与删除

**下载**

- 下载按当前应用的读取／下载授权返回流式内容，支持 Range、可用的 ETag／版本条件和下载文件名。
- OA 后端转发时传递适用的范围与版本信息，并处理浏览器取消。文件内容按块发送，资源使用受共享带宽和并发预算约束。
- 对象变化、权限失效、无效范围和网络中断返回相应状态。鉴权下载与视频分享共用底层读取和取消能力，访问资格分别按各自令牌核验。

**删除**

- 文件及目录删除要求显式删除能力，复用根保护、对象身份检查、路径协调和套件的递归删除任务。
- 受理后返回任务标识，由 OA 查询进度、结果与取消状态。目录删除可展示部分完成和失败项，真实永久删除／回收站语义在能力信息和提交结果中说明。
- 每个修改请求关联幂等标识，并携带可用的预期对象／版本信息。响应丢失后查询原任务，路径被其他文件重用时重新核验目标，重试沿用原操作意图。

## 6. NAS 账号与权限管理

本项按管理实际 NAS 账号及访问权限规划，OA 通过 API 完成账号开通、分组和目录授权。服务内增强能力、分享能力与 OA 应用授权也提供对应管理能力，分别声明授权对象、作用范围和实际生效位置。

### 6.1 账号相关接口

| 能力 | 计划内容 |
| --- | --- |
| 账号查询 | 按管理员允许的账号范围分页查询、查详情和检查用户名占用，返回稳定账号 ID、所属后端、状态及可见分组 |
| 创建账号 | 提交用户名、必要资料及凭据初始化方式，返回实际账号 ID 和创建结果，支持关联原创建请求查询 |
| 资料与状态 | 修改允许的账号资料、启用／停用状态，按后端实际支持的字段声明能力 |
| 凭据重置 | 单独授权密码初始化／重置，遵循实际 NAS 密码规则。凭据通过受保护通道交付，日志、任务记录及诊断仅保存操作结果 |
| 分组管理 | 查询可见用户组和成员，在管理员允许的组范围内增加／移除账号成员关系 |
| 开通结果 | 分别呈现账号创建、分组、目录授权的完成情况，部分成功或响应丢失时使用原任务核对和续办 |

账号身份包含管理后端和稳定账号 ID。用户名用于展示及输入校验，已有同名账号返回明确冲突或现有对象查询结果，由调用方按已确认身份发起后续操作。重复创建请求通过应用、幂等标识和原请求内容核对，重试返回原任务与结果。

### 6.2 权限查询与修改

| 权限层 | 计划内容 |
| --- | --- |
| NAS 共享与文件权限 | 查询账号／组对共享根、目录和文件的授权项，按后端能力增量修改读取、写入、创建、删除等权限，标明共享级与文件系统 ACL 的来源 |
| 继承与批量范围 | 明确仅当前对象、继承规则及递归调整范围，批量／递归修改使用可查询任务，返回已确认项和失败项 |
| NFM 服务授权 | 查询和调整指定账号／组的递归删除、复制、受限上传收尾、分享等服务能力及授权根 |
| OA 应用授权 | 查询和调整获准管理的应用能力与目录范围，受调用方管理权限及可授予上限约束 |

- 响应同时给出可用的显式授权、继承来源与实际可确认的有效权限。读取、写入、删除、重命名等实际行为按后端映射和权限交集验证，后端无法可靠计算的字段声明为未知。
- 修改请求指定账号／组、目标身份、范围和变更项，保留其他主体及未涉及的授权项。提交携带可用的预期权限修订，后端支持条件更新时使用其原子校验能力，其他后端按实际竞争保障决定可开放的操作。
- 服务读回真实后端结果后记录确认状态，区分成功、部分完成、版本变化、权限拒绝和结果待确认。共享授权与文件 ACL 分阶段调整时分别记录结果。
- 账号停用、分组或权限变化后，重新核验相关 NFM 会话、能力缓存与新请求。进行中任务和分享按既有授权、撤销与结果核对流程处理，记录实际生效范围和仍待确认的状态。

### 6.3 管理后端与授权范围

管理员为账号管理和权限写入配置实际可执行、可读回核验的管理后端。账号创建、凭据重置、组成员、共享权限、文件 ACL 各自公布支持能力，支持矩阵按 NAS／目录服务和实际接口分别验证。现有文件挂载、登录核验和文件读写能力沿用各自用途。

OA 应用分别获得账号查询、创建、资料／状态修改、凭据重置、分组和权限读写能力。管理范围限定到后端、账号／组、授权根及可授予权限上限，包含管理员账号和高权限组的变更须在对应委托范围内。服务管理凭据由 NAS 侧按用途受控保存，OA 使用自身受限应用凭据调用。

普通文件调用继续使用第 2 节的执行身份与权限交集，账号管理调用使用单独核验的管理委托。管理后端暂不可用、权限不足或某类写入能力尚未实现时，返回相应稳定原因码与实际能力信息。首批管理后端及受支持 NAS 版本在实施前冻结。

### 6.4 任务与审计

账号开通及权限变更关联应用、已核验调用身份、目标稳定 ID、范围、请求与任务 ID。创建、分组和授权的分步结果持久保存，响应丢失、服务重启及部分失败后先查询原任务并读回核对，再处理剩余步骤。停止任务后报告已生效项与停止结果。

管理员审计保存必要的变更前后授权、作用范围、执行结果和时间，按独立查看权限与保留规则查询。密码、访问令牌等凭据采用专用保护和传递流程，通用调用日志、任务详情及可导出诊断使用脱敏的结构化操作字段。管理说明、状态与稳定错误覆盖简体中文、香港繁体中文和英文。

## 7. 接口目录草案

下列候选路径以服务部署入口为基准，反向代理前缀由配置统一追加，用于划定首版契约范围。最终字段、HTTP 状态和认证方式在 OpenAPI 契约中确定。

| 方法与候选路径 | 用途 |
| --- | --- |
| `GET /api/v1/capabilities` | 查询接口版本和本人应用能力 |
| `GET /api/v1/roots` | 查询授权目录 |
| `GET /api/v1/files` | 查询某目录的分页列表 |
| `GET /api/v1/files/stat` | 查询文件或目录详情 |
| `POST /api/v1/uploads` | 登记上传任务 |
| `PUT /api/v1/uploads/{uploadId}/content` | 流式发送文件内容，具体续传契约待确定 |
| `GET /api/v1/uploads/{uploadId}` | 查询上传阶段、已确认位置及结果 |
| `POST /api/v1/uploads/{uploadId}/complete` | 核验并提交正式文件 |
| `DELETE /api/v1/uploads/{uploadId}` | 取消上传并收尾本任务临时对象 |
| `GET /api/v1/files/content` | 下载文件，支持范围请求 |
| `POST /api/v1/file-deletions` | 提交文件或目录删除任务 |
| `GET /api/v1/jobs/{jobId}` | 查询任务结果 |
| `POST /api/v1/jobs/{jobId}/cancel` | 请求取消任务 |
| `GET /api/v1/accounts` | 查询可管理 NAS 账号及用户名占用情况 |
| `GET /api/v1/accounts/{accountId}` | 查询指定后端中的账号详情 |
| `POST /api/v1/accounts` | 创建 NAS 账号，返回账号开通任务 |
| `PATCH /api/v1/accounts/{accountId}` | 修改允许的资料及启用／停用状态 |
| `POST /api/v1/accounts/{accountId}/credential-resets` | 初始化／重置凭据，单独授权 |
| `GET /api/v1/groups` | 查询可见用户组 |
| `GET /api/v1/groups/{groupId}/members` | 查询允许管理的组成员 |
| `PATCH /api/v1/groups/{groupId}/members` | 增量调整允许管理的组成员 |
| `GET /api/v1/permissions` | 查询指定主体、目标及权限层的当前授权和可用修订 |
| `POST /api/v1/permission-changes` | 提交 NAS／NFM 服务权限变更任务 |
| `GET /api/v1/applications/{applicationId}/grants` | 查询允许管理的 OA 应用授权 |
| `PATCH /api/v1/applications/{applicationId}/grants` | 在管理委托上限内调整 OA 应用授权 |

错误响应包含稳定原因码、请求 ID、操作和阶段，长任务补充任务 ID。区分身份失效、权限拒绝、不存在、名称冲突、版本变化、输入错误、限流、后端失败及结果待确认。账号／权限接口补充管理能力不支持、管理后端不可用、用户名占用、凭据规则不符、管理范围越界和部分授权完成。OA 可按稳定码展示业务文案，服务端的内部错误与诊断按权限留存。

## 8. 实施和验证

先复用身份、根映射和任务基础，接入只读查询与下载，再完成 HTTP 上传和删除。账号／权限管理先验证独立管理后端、委托范围和只读查询，再接创建、凭据、分组及权限写入；接口稳定后完成 API 中心管理界面与 OA 联调。OpenAPI 文档和实现使用同一份契约维护，示例以通用测试目录和占位凭据编写。

重点覆盖以下场景。

- 独立应用授权、目录范围与权限交集，凭据轮换／撤销，跨应用查询和操作任务的隔离。
- 分页及目录变化、空目录、文件夹详情、中文／空格／特殊字符、可空元数据和后端版本能力。
- 上传正常提交、中断续传、重复分块／提交、错误大小或校验、空间不足、抢占目标、取消及清理失败。
- 下载完整内容、Range、版本变化、断开释放及慢客户端，资源占用保持在配置预算内。
- 文件／目录删除、部分失败、停止状态、响应丢失、重启核对、目标替换以及幂等结果。
- 账号创建、同名冲突、重复请求、重置凭据、启用／停用、组成员范围、管理后端不支持与不可用，返回实际阶段和稳定原因。
- NAS 授权、服务能力与 OA 应用授权的范围校验、可授予上限、显式／继承权限、其他主体保留、条件竞争、递归部分完成和读回核验。
- 创建后分组／授权失败、响应丢失、任务停止、服务重启及续办，校验原账号身份与已完成步骤，结果准确关联原请求。
- 账号／权限变更后的会话与缓存生效、调用方越界和试图扩大自身管理范围，以及管理凭据、密码、令牌的日志与导出保护。
- 调用记录可关联实际请求、应用和任务，公开导出采用脱敏字段，凭据与文件内容按访问边界保护。

OA 集成验收使用可丢弃的测试目录和专用测试账号，依次完成列目录、查详情、上传、下载校验和删除，并验证账号创建、分组及授权后实际使用 SMB／WebDAV 的权限。同步验证应用权限变化、撤销、部分开通、失败重试及较大文件资源占用。界面与实际 OA 操作由用户验收，实施进度纳入服务端路线图。[路线图](roadmap.md)

## 9. 当前状态与待确定项
