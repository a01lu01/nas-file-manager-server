## 验证安排

文档修改只做差异、链接、格式及公开内容检查，不触发 App、原生、容器或云构建。代码阶段每个逻辑提交跑受影响测试；整批冻结后合并必要的完整测试、目标构建和产物核验，已通过且输入未变的平台不反复编译。

重点用例按模块复用夹具：

- **身份与边界**：伪造发现配置、错误密码、匿名成功、同名用户、换账号／撤销、越界和链接竞争；明确“登录成功”不等于修改授权。
- **作业与回退**：重复提交、响应丢失、仍运行、停止未确认、部分完成、过期／丢失记录、进程重启和源／目标替换；没有受理证据或结果未知时不盲目换通道执行。
- **删除与复制**：空／深／宽目录、同名编号、目标认领、空间不足、源变化、只读／无删除权限、未确认句柄与保护路径；不用用户真实业务数据做破坏性自动测试。
- **上传收尾**：持久／流式与两种协议；独立授权开关、伪造任务、他人对象、仅后缀认领、部分数据、抢占目标、确认丢失、取消与清理失败；完成后仍不能修改既有正式文件。
- **事件识别**：正常零补查、去重、注册窗口、树移入、溢出、重放、日志轮转及预算；未知上传人不猜测，未完成文件不误发布。
- **分享与映射**：地址确认和重启、可信改名／换版与歧义、人工决定保护、旧版本存在／缺失、权限／撤销／到期、并发发布、Range／Seek 版本隔离及备份恢复。
- **网页播放器**：七档倍速、长按后恢复原速度及取消清理，缩放与控件手势隔离，自动隐藏／菜单／键盘焦点，播放受限与失败区分，重试隔离、本地进度与换版提示；实际浏览器的全屏、音量、窄屏和触控表现由用户验收。
- **分享网络**：不触发 NAS 视频转码，Range 与流式读取、点击前加载、关闭／切换／Seek 取消、缓存与访问核验、并行请求的会话／出口预算；不将限速记为码率降低。手机／电脑预压缩后沿用已核验的版本映射。
- 分享访问与观看统计验证免登录／登录、媒体权限、账号归属、倍速／Seek／续看区间、有效时长、并发去重、换版及断网补报，记录真实浏览器误差与 NAS 开销。[登录与观看统计计划](video-analytics.md)
- API 中心验证独立应用与目录授权、列表分页／详情、HTTP 上传续传与提交、范围下载、删除任务与幂等、凭据轮换／撤销及调用记录，并使用 OA 测试目录完成联调。[API 中心计划](api-center.md)
- **部署与兼容**：真实目标架构、目录权限、持久卷、网络／TLS、原协议兜底、API 能力协商、服务升级和三语资源。

性能对照使用相同 NAS、网络、文件树和账号，分别记录枚举、执行、核验、完整耗时与请求量；覆盖大量小文件、大文件、空目录及多级目录，记录停止／断网／App 退出／容器重启。部署 Docker 不等于自动提速，结论以用户实测为准。

分享网络按相同视频版本、观看区间和并发条件对照，记录实际发送字节、读取量、请求数、首帧／Seek 等待及 CPU／内存，覆盖短看退出、复看、缓存淘汰和换版。手机／电脑预压缩成品单独计量，不预设带宽改善比例；完整范围见[分享设计第 6.2 节](video-sharing.md)。

界面、交互、实际权限与真实 NAS 验收由用户完成；App 的 SMB 标准／加速模式与 WebDAV 分别确认。已验证且本轮未受影响的功能无需全面重测，平台或设备结果不互相替代。
