# 视频分享登录与观看统计计划

记录日期 2026-11-12。新增需求包括每条分享可配置免登录或登录后观看，查询链接播放次数和时长，登录模式进一步查询账号的观看时间与完播进度。本文件记录需求与统计口径草案，具体身份后端、判定门槛、采样间隔和保留期限在实施前确定。

## 1. 分享访问方式

管理员设置全局默认方式及允许的范围，创建者为分享选择访问方式。已有有效期、提取码、下载和撤销规则与新访问方式共同生效。

| 方式 | 访问与统计 |
| --- | --- |
| 免登录观看 | 校验分享凭证和访问策略后播放，按匿名观看会话统计访问、播放次数、有效时长和会话覆盖率 |
| 登录后观看 | 校验分享与账号身份，按允许的账号／组范围授予播放权限，将会话绑定到已验证账号，提供账号明细与累计覆盖率 |

初稿优先复用管理员配置的 NAS 身份后端。接入 OA 统一登录时需建立已验证身份映射，具体协议待确定。观看会话的权限限定到当前分享和资产，目录访问、下载与管理能力使用各自的授权规则。

登录身份采用身份后端命名空间和经核验的账号标识，显示名称独立维护。匿名会话由 NAS 签发随机标识，统计页显示匿名会话数。账号统计使用登录成功后由服务端确认的归属。

访问方式修改形成新的策略修订，页面、媒体 Range 和新会话重新校验当前策略。登录、退出或换账号时结算原会话并创建相应的新会话，历史数据保留采集时的身份与策略修订。

## 2. 统计口径

| 指标 | 计算方式 |
| --- | --- |
| 链接访问次数 | 成功取得分享观看页的访问会话数，页面刷新按访问规则登记 |
| 播放次数 | 一次观看会话首次产生有效播放进展时计一次，暂停、拖动及内部重试归入原会话，主动重播或新的观看会话另计 |
| 单次有效观看时长 | 播放实际推进期间的真实经过时间，暂停、缓冲和 Seek 阶段暂停计时 |
| 累计／平均会话时长 | 累计值为有效会话时长求和，平均值为累计值除以有效播放次数，账号去重时间另列 |
| 内容覆盖时长 | 当前视频版本实际播放过的媒体时间区间合并、去重后的总长度 |
| 账号完播进度 | 同账号、同分享、同视频版本的内容覆盖时长除以有效视频时长，结果限制在 0% 至 100% |
| 完播状态 | 账号或会话的覆盖率达到管理员配置的判定门槛，界面同时展示实际覆盖百分比 |
| 登录账号完播率 | 选定范围内产生有效播放的去重账号中，截至所选统计时点累计覆盖达标的账号数占比，按视频版本计算 |
| 播放时间记录 | 服务端记录首次播放、每次会话开始／结束、最近观看时间，并附有效观看时长和覆盖进度 |

完播门槛默认值待确定。账号明细展示实际覆盖率，汇总报表标明门槛、视频版本、日期范围和账号统计群体。观看者数量为零时，界面显示暂无数据。

匿名模式展示会话维度的覆盖和完播比例。登录模式将多次会话聚合到账号，跨设备的同账号区间取并集。统计汇总标明时间范围内增量与截至查询时的累计进度，账号完播状态保留首次达标时间。

## 3. 倍速、拖动、续看与并发

- 倍速分别记录真实耗时与内容覆盖。以 2× 连续观看视频内容 2 分钟时，真实有效时间约为 1 分钟，内容覆盖增加约 2 分钟。
- Seek 创建新的区间边界，跳转前后的未播放区间保留空缺。结束事件与已确认覆盖区间共同用于会话收尾和完成判定。
- 重播增加累计有效观看时长，覆盖率使用区间并集。账号多次续看的已确认区间持续合并，最后播放位置独立记录。
- 同账号、同分享及同视频版本的并发会话合并覆盖区间，账号级有效观看时间对重叠时间窗口去重，同时保留各次会话明细。
- 前台且产生可验证播放进展的时段计入有效观看。原生全屏／画中画按浏览器提供的可核验状态处理，后台时段的最终口径通过兼容性测试确定并展示于统计说明。
- 视频时长使用当前资产可验证的元数据，时长暂缺时保留已确认区间并显示待计算，元数据就绪后核对覆盖率。

## 4. 查看入口与权限

分享创建者及获授权管理员可打开该分享的统计面板，权限范围随账号与分享归属核验。面板提供以下内容。

| 页面 | 显示内容 |
| --- | --- |
| 链接概览 | 访问次数、播放次数、累计／平均会话有效时长、匿名会话数、登录观看账号数及当前版本 |
| 账号明细 | 账号、播放次数、去重有效时长、覆盖时长／进度、完播状态、首次／最近观看时间和数据状态 |
| 单次播放 | 会话开始／结束时间、已确认有效时长、倍速变化、覆盖进度和结束状态 |
| 筛选 | 分享、日期范围、视频版本、账号及完播状态 |

统计查询按分享的管理权限执行。接收方获得的观看凭证用于播放会话，管理端按独立授权查询账号信息与统计。全部入口、指标说明、错误及辅助功能名称覆盖三语。

## 5. 数据采集与弱 NAS 资源预算

1. NAS 在访问校验后签发观看会话，绑定分享、逻辑视频、资产版本、策略修订和已验证账号或匿名标识。
2. 播放器采集播放进展、暂停、缓冲、Seek、速度变化、可见状态和结束信息。媒体下载字节与播放事件分别进入网络计量和观看计量。
3. 周期性批量上报，并在暂停、结束、离开或会话切换时尽力提交剩余数据。具体间隔、批量大小和补报窗口以资源与丢失测试确定。
4. 服务端核验会话归属、事件序号、时间跨度、速度与位置变化，按会话和序号幂等接收。乱序、重复和迟到数据通过已记录状态核对。
5. 使用有界接收队列、合并区间和分批持久化，维护会话与账号聚合。原始事件、会话与汇总记录分别设置保留和清理预算。
6. 客户端补报队列有界，统计故障使用独立重试和状态提示，播放流程继续处理媒体。管理页标明已确认、待补报或上报中断。

统计覆盖浏览器已上报且服务端核对的播放行为。断网、强退或浏览器终止时，末尾数据可能缺失，汇总保留已确认值和数据状态。异常时间或位置跃迁进入核验，统计精度与误差通过实际浏览器测试记录。

## 6. 本地继续播放与服务端统计

播放器保存在当前浏览器的进度用于继续播放。NAS 端保存本计划规定的观看会话、已确认区间和账号聚合，用于统计查询。管理端的统计数据状态与播放器的继续播放位置分别展示。

同一资产改名后沿用对应统计。视频内容换版后按新资产版本独立计量，历史版本可查询。链接概览可以汇总各版本播放量，并展示按版本计算的完播数据。版本之间的学习／观看完成关系在产品需要时另行确定。

统计由当前 NAS 持久保存，使用已授权范围内必要的账号标识和观看记录。管理员配置查询角色、记录保留与清理策略。观看页说明采集信息和用途，诊断导出采用脱敏字段，业务统计通过专用权限查询。

## 7. 记录与接口方向

分享记录补充访问方式、允许观看范围、策略修订及统计配置。新增观看会话、已播放区间与聚合记录，沿用服务实例和根／视频的归属关系。

统计写入接口使用 NAS 签发的当前观看会话，统计查询接口使用获授权的管理身份。事件关联分享、视频、资产、会话与递增序号，接口字段与存储模型在实现时通过同一契约维护。

## 8. 实施与验证

先接入访问方式和登录会话，再完成播放器采集、去重聚合和统计面板。登录校验接入页面、媒体读取和 Range 路径，缓存复用按当前访问资格与资产版本核对。

- 免登录、登录后观看、允许账号／组、身份后端、换账号、策略切换、到期与撤销覆盖真实访问链路。
- 仅打开页面、实际播放、暂停／缓冲／Seek、重播、内部重试分别核对访问数、播放数、时长与区间。
- 倍速、长按临时加速、多次续看、拖动到末尾、并发多标签／多设备，核对覆盖率、真实时长和账号聚合。
- 事件重复、乱序、迟到、身份切换、时钟偏差、断网补报、强退及队列预算，验证归属、幂等和数据状态。
- 同资产改名、内容换版、未知时长、保留清理和服务重启，核对版本、历史明细及已确认统计。
- 使用确定的播放／暂停／Seek／倍速脚本与人工观察对照，测量上报误差、CPU、内存、写入量及多人并发。

用户在实际 iOS、Android 和使用中的浏览器验收登录、观看与管理面板。最终冻结账号来源、完播门槛、后台口径、上报间隔和保留策略，并记录实际统计误差与资源开销。

## 9. 当前状态

已记录免登录／登录访问及账号观看统计需求。指标和身份方案为设计草案，代码实现、接口联调、浏览器准确度及 NAS 性能验证待后续阶段完成。
